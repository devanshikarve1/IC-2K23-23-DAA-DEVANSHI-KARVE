# Linear Search

## Problem Statement
Implement Linear Search to find an element in an array.

## Algorithm / Approach
Check each element one by one until the required element is found.

## Time Complexity
Best: O(1)
Average: O(n)
Worst: O(n)

## Space Complexity
O(1)

## Sample Input
Array: 10 20 30 40 50
Target: 30

## Sample Output
Element found at index 2.

## Learning Outcomes
Understanding of Linear Search and its time and space complexity.
